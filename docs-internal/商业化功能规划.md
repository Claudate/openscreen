## 二、Cap 现状基线(源码核对 · 含架构师 Agent-3 实测纠偏)

> ⚠️ **重要纠偏**: 产品初判"Cap 只有手动关键帧、缺录完自动生成"经架构师实测源码证实**不准确**。Cap 的自动聚焦**全链路框架已通**(采集→生成→渲染→开关→UI)，真正命门是**自动生成算法质量太糙**(MVP 级)。这把 P0 从"从零造轮子"降级为"升级单个算法函数"，工作量与风险大幅下降，差异化价值不变。

| 维度 | Cap 现状(实测) | 与标杆差距 |
|---|---|---|
| 自动缩放-数据层 | ✅ **零缺口**: `crates/recording/src/cursor.rs` 16ms≈60Hz 采集点击/移动/键盘(带精确 time_ms)，5s 增量 flush 崩溃可恢复 | 数据全有 |
| 自动缩放-生成层 | ⚠️ **两条自动路已存在但算法糙**: ①录完自动(`recording.rs` `auto_zoom_on_clicks`) ②编辑器一键(`ZoomTrack.tsx` `generateZoomSegmentsFromClicks`)。核心函数 `generate_zoom_segments_from_clicks_impl`(recording.rs L3071-3147) | ❌ amount 硬编码 2.0 / `_moves` 弃用 / 不定位点击坐标 / 合并间隔一刀切 / 缓动全默认 / 不感知滚动打字拖拽 → 这是被评 "Limited zoom" 的**真因** |
| 自动缩放-渲染层 | ✅ **已 SS 级**: `crates/rendering/src/zoom.rs` 弹簧缓动+跟随中心+防出界+完整测试 | 无差距，改造不碰它 |
| 光标 | 基础展示；扩展位已铺(`cursor_interpolation.rs`+`CursorConfiguration`/`ClickSpringConfig`) | ⚠️ 平滑/放大/高质量替换/点击特效需消费逻辑 |
| 字幕/AI | ✅ 云转录 Deepgram nova-3(15 语种) + 本地 Whisper/Parakeet + Groq→gpt-4o-mini 摘要(有兜底链)；⚠️ 音频增强代码已写但**未接线**(`_enhanceAndSaveAudio`) | ⚠️ 去填充词/静音移除/按转录剪辑(词级时间戳已有)缺消费逻辑 |
| 编辑器 | 分层渲染管线(background→blur→display→cursor→camera→mask→text→captions→keyboard)，加效果=新增 layer+注册一行 | ✅ 扩展性极好，缺设备框/横竖屏/快捷键浮层/运动模糊的消费实现 |
| 导出 | 本地 MP4 + 云分享链接 | ⚠️ 缺社媒预设/竖屏/GIF 优化的"一键多平台" |
| 商业框架 | Cap Pro($8.16/月起) + 商业许可 + 自部署 + 云 + S3 + Loom 导入器 | ✅ 已具备，是变现地基 |

> 技术栈: TypeScript(48%) + Rust(46%)，Tauri 原生，AGPLv3 + 采集层(cap-camera*/scap*) MIT。GitHub 19.5k★。
> **合规关键**: 官方商业许可"仅约束 Cap 官方分发的二进制，不约束用户自编译版本"——这是 AGPLv3 下的合法变现支点。
> **架构师护城河建议**: 改 Rust 核心(含聚焦算法)须开源(可做"开源 Pro"卡口碑)；真正闭源护城河放在**独立增值服务层**(云 AI 编排/模板后端/企业管控)，新建独立仓库经 API 与 AGPL 本体解耦。

## 三、功能差异化清单(P0/P1/P2 分档)

### P0 — 必做(自动聚焦相关具体增强，直接对标 Screen Studio 尖刀)

> **路线确认(已与架构师对齐)**: P0 核心 = **升级 `generate_zoom_segments_from_clicks_impl` 算法质量**，而非从零造自动生成。这是"最小改动撬动最大差异化"的支点，AGPL 内闭环。

| # | 功能 | 具体增强点(精确落点) | 创作者价值 |
|---|---|---|---|
| P0-1 | **升级自动缩放生成算法** | 改造 `recording.rs L3071-3147` 核心函数：①缩放强度自适应(替代硬编码 2.0，按点击区域/控件大小动态) ②**复活被弃用的 `_moves` 移动轨迹**(信息利用) ③**生成阶段定位点击坐标**做精准聚焦中心 | 直击被评 "Limited zoom" 的真因，一函数撬动核心卖点 |
| P0-2 | **缩放智能策略(聚类+场景感知)** | 点击时间聚类替代一刀切 `MERGE_GAP=2500ms`；缓动曲线/强度/最小间隔/防抖阈值可调；**感知滚动/打字/拖拽场景**差异化缩放；空闲自动还原 | 让自动缩放"丝滑不晕"，达到 Screen Studio 观感 |
| P0-3 | **光标增强** | 接 `cursor_interpolation.rs`+`CursorConfiguration`：抖动轨迹平滑；光标放大+高质量替换；接 `ClickSpringConfig` 做点击高亮/涟漪 | 拉满专业感，零额外操作 |
| P0-4 | **运动模糊** | 接 `screen_motion_blur`：缩放/平移加电影级运动模糊(参数可调) | 与平滑联动，是"高级感"的关键最后一步 |
| P0-5 | **键盘快捷键可视化** | 接 `keyboard.rs` layer+`KeyboardSettings`：录制中按键浮层(可开关/换样式) | 软件教程刚需，几乎所有竞品都有 |

> 注: P0-3/P0-4/P0-5 架构师确认扩展位已在分层渲染管线铺好，加 layer 模块+注册一行即可，不破坏现管线。

## 四、变现模式建议(结合 AGPLv3)

### 4.1 AGPLv3 约束下能做什么

> AGPLv3 = 可商用，但**分发或作为网络服务提供时必须开放源码**(网络条款)。不能简单"闭源打包卖 License"。但 Cap 官方已验证的合法路径仍多。

| 变现方式 | AGPLv3 合规性 | 现实度 | 说明 |
|---|---|:---:|---|
| **云服务订阅(SaaS)** | ✅ 完全合规 | ★★★★★ | 托管/存储/转码/AI 算力是真实增值；自部署者照样得自己掏云成本。**最稳现金流** |
| **商业使用许可** | ✅(Cap 已在做) | ★★★★☆ | 桌面免费、商用需买许可；**只约束官方分发的二进制**，自编译不受限——AGPL 下合法 |
| **AI 增值订阅/用量** | ✅ 合规 | ★★★★★ | 转录/去填充词/摘要/克隆走云算力按量计费，价值直观，毛利可控 |
| **企业版(托管+SSO+支持)** | ✅ 合规 | ★★★★☆ | 私有部署支持、SSO/SCIM、SLA、合规审计、专属支持(卖服务非卖代码) |
| **模板/素材市场抽成** | ✅ 合规 | ★★★☆☆ | 内容生态非软件本体，平台抽成 |
| 闭源卖断 App | ❌ 违反 AGPL | ✗ | 不可行 |

### 4.2 推荐变现组合(主次分明)

1. **主引擎 — 云订阅 + AI 用量**(对标 Loom Business+AI)
   - Free: 本地录制+基础自动缩放+5 分钟分享链接(获客)
   - **Pro 订阅**(沿用 Cap Pro ~$8/月，低于 Loom $18/Screen Studio $29 打性价比): 无限云存储/分析/全套自动缩放+光标增强+横竖屏
   - **AI 加油包**: 去填充词/转录剪辑/摘要/克隆按量或包月
2. **副引擎 — 商业许可买断**(吃 Screen Studio 出走的买断党)
   - 一次性"桌面商用许可"(含 N 年更新)，纯本地创作者不碰云也能合法商用 → **填补 Screen Studio 转订阅留下的空白**
3. **企业引擎 — 自部署企业版**
   - 私有化部署 + SSO/SCIM + SLA + 专属支持 + 品牌资产库(卖服务，AGPL 完全合规)
4. **生态 — 模板/素材市场**(后期，抽成)

> **一句话策略**: 用 **Free 获客 → Pro 订阅留存 → AI 用量提毛利 → 买断许可吃出走党 → 企业版做高客单**，AGPLv3 全程合规，且靠"双轨定价"形成对所有单模式竞品的结构性碾压。

## 五、给团队的协作输入

- **给架构师(Agent-3)**: P0-1/P0-2 的技术落点 = 录制阶段的鼠标事件流捕获 + 自动 zoom 关键帧生成器，接到现有编辑器 zoom 管线；请评估 `crates/recording` 事件捕获与 `crates/editor` 渲染管线的扩展可行性。
- **给设计师(Agent-4)**: P0 自动缩放需要"录制中实时反馈 + 编辑器可视化调参(强度/速度曲线)"的交互；快捷键浮层、设备框、横竖屏切换都需 UI 设计。建议先攻自动缩放调参面板。
